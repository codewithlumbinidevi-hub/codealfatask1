# 🌍 AI Multilingual Translator

A modern AI-powered language translation web application built using Python, Streamlit, and Google Translate API.

## 🚀 Features

- Translate text across 35+ languages
- AI-powered language translation
- Modern and responsive UI
- Source and target language selection
- Language swap functionality
- Translation history
- Auto language detection
- Copy translated text
- Download translated text as TXT
- Statistics dashboard
- Dark mode support
- Error handling and user-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Deep Translator
- Google Translate API
- HTML/CSS (Custom Styling)
